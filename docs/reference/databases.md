# Reference: databases

Store source records, derived intelligence, human decisions and operational history in separate SQLite databases.

Files covered:

- `database_manager.py`
- `project_paths.py`
- `backup_databases.py`
- `db_query_tool.py`
- `supabase_migrate.py`

`database_manager.py` defines source schemas, migrates missing columns, normalizes item fields and upserts by stable identity/URL. Content hashes separate new, updated and unchanged items. It merges legacy BuyICT URL duplicates, preserves raw currency text beside numeric values, and removes placeholder phone values. `project_paths.py` anchors paths to the checkout: `AUSTENDER_DB_DIR` can select an absolute directory or a project-relative one. The schema inventory below comes from code, not database contents. There is no `databases/` directory in this worktree; deployed database presence, extra tables and row counts are unverified.

| Module | Interface and effects |
|---|---|
| `database_manager.py` | `DatabaseManager.SCHEMAS`, `get_connection`, `initialize_database`, `insert_item`, `get_state`/`set_state`, and query helpers support collectors. `crawl_state` stores per-source key/value checkpoints; timestamps and `all_details` retain provenance. |
| `project_paths.py` | Exposes `PROJECT_DIR` and `database_directory()`; does not read data itself. |
| `backup_databases.py` | SQLite online backup to `.partial`, then rename. Daily copies default to 14-day retention; `contract_api.db` is weekly with two copies retained. Also copies `inputs/` and `local_assistant/inputs/` by path, preserving reviewed private material. `--keep` changes daily retention. |
| `db_query_tool.py` | Lists databases, schemas and summary stats; queries a selected source and optionally exports CSV. Flags: `--list`, `--info`, `--query`, `--spider`, `--export`, `--stats`. This administrative helper is separate from the restricted public API. |
| `supabase_migrate.py` | Copies SQLite tables into named PostgreSQL schemas, translating types, ordinary indexes and compatible views. Replaces each table transactionally; skips SQLite full-text internals. Packs supported data files into `files.documents`, creates CSV/workbook tables, and translates the optional hybrid cache to pgvector. Reads `SUPABASE_DB_URL`; supports `--dry-run`, `--only`, `--skip-files`, `--skip-databases`. Requires `psycopg` at execution time; it is not listed in the checked-in requirements files. |

| `data_quality.db` | Writer unverified: no creation statements found in repository Python modules | Consumers expect `contract_checks`, `abn_candidates`, `quality_findings`, `registry_identity_checks`; full schema and row semantics are unverified. | Optional intelligence quality projections and API allowlist. |

The optional `local_assistant/runtime/hybrid.db` is outside `databases/`: `embeddings` maps text hashes to text/vector blobs, and `metadata` records cache/model details. It is rebuildable retrieval state, not a source of contract facts. `databases/sheets_registry.json` is a private non-SQLite publication registry. Cloud immutable generations and operations backups are described in [cloud-and-daily-brief.md](cloud-and-daily-brief.md).
